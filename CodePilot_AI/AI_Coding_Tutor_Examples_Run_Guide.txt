AI CODING TUTOR
START-TO-END RUN GUIDE + EXAMPLES

==================================================
PART 1 - START THE PROJECT
==================================================

PROJECT FOLDER:

CodePilot_AI_Complete

STEP 1:
Open the project folder in VS Code.

STEP 2:
Open:

Terminal -> New Terminal

STEP 3:
Activate the virtual environment:

.venv\Scripts\Activate.ps1

You should see:

(.venv) PS C:\Users\YourName\Downloads\CodePilot_AI_Complete>

STEP 4:
Install requirements if needed:

pip install -r requirements.txt

STEP 5:
Check the .env file in the MAIN project folder.

It should contain:

GOOGLE_API_KEY=YOUR_GEMINI_API_KEY
GEMINI_MODEL=gemini-3.6-flash

Never share your API key.

STEP 6:
If you added or changed knowledge files, update the RAG database:

python backend/ingest.py

STEP 7:
Start the application:

python -m streamlit run backend/app.py

STEP 8:
Open:

http://localhost:8501

PART 2 - BASIC TEST
==================================================

Programming language:
Python

Tutor mode:
Debug my code

Question:

Why does this code give an IndexError?

numbers = [10, 20, 30]
print(numbers[3])

Expected idea:

Python list indexes start from 0.
The valid indexes are 0, 1 and 2.
Index 3 does not exist.

Correct code:

numbers = [10, 20, 30]
print(numbers[2])

PART 6 - OPTIMIZE MY CODE EXAMPLES
==================================================

EXAMPLE 1 - Sorting

Programming language:
Python

Tutor mode:
Optimize my code

Question:

Optimize this code and explain the time complexity:

numbers = [5, 2, 8, 1, 9]

for i in range(len(numbers)):
    for j in range(i + 1, len(numbers)):
        if numbers[i] > numbers[j]:
            numbers[i], numbers[j] = numbers[j], numbers[i]

print(numbers)

Ask:
- Is there a faster or simpler solution?
- What is the time complexity?
- Why is the optimized version better?
